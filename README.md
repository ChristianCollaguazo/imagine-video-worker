# Imagine Video Worker · LightWan

Worker privado de imagen a video con LightWan 2.2 A14B NVFP4 y LightX2V.
Implementa la interfaz HTTP de Imagine y se despliega como imagen Docker
`christiancollaguazo/imagine-video-worker:lightwan-v1`.

Consulta [README-Docker.md](README-Docker.md) para configurar, diagnosticar y
medir el worker. El historial de Git conserva la implementación original H3
en `1a0eb25`.
